# 要件定義

## 1. アプリの目的

読んだ本を忘れず記録し、後から振り返れるようにする。

## 2. 想定ユーザー

自分自身。

MVPでは他のユーザーへの提供を前提としない。

## 3. 解決したい課題

読んだ本を記録しておかないと、
時間が経ったときに「何を読んだか」を忘れてしまう。

## 4. 本に保存する情報

- タイトル
- 著者
- 評価（5段階）
- 読了日時

## 5. MVP機能

### 本の登録

- タイトルを入力できる
- 著者を入力できる
- 評価を5段階で設定できる
- 読了日時を設定できる

### 本の一覧

登録した本を一覧で表示できる。

表示項目：

- タイトル
- 著者
- 評価
- 読了日時

### 本の編集

登録済みの本の情報を変更できる。

### 本の削除

登録済みの本を削除できる。

### 本の並び替え

- 読了日時が新しい順
- 読了日時が古い順
- 評価が高い順
- 評価が低い順

## 6. MVPで作らない機能

- 本の検索
- フィルター
- 感想
- 印象に残った文章
- ISBN検索
- Google Books API
- 本の表紙自動取得
- AI機能
- SNS機能
- 読書統計
- 読書カレンダー

## 7. 開発方針

自分自身が実際に使うことを前提として開発する。

最初から多くのユーザーへの対応や
大規模なサービス設計は行わない。

まずは、

登録 → 一覧 → 編集・削除 → 並び替え

という基本的な読書管理機能を完成させ、
実際に自分で利用する。
