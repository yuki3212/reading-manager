# 画面設計

## 1. 画面一覧

| 画面 | 目的 |
|---|---|
| ログイン画面 | アプリへのログイン |
| 本棚画面 | 登録した本を一覧で確認・並び替え |
| 本登録画面 | 新しい本を登録 |
| 本詳細画面 | 本の情報を確認・編集・削除 |
| 本編集画面 | 登録済みの本を編集 |

---

## 2. ログイン画面

### 目的

ユーザーがアプリにログインする。

### 表示内容

- アプリ名
- Googleログインボタン

### 操作

- Googleログイン

### 遷移

ログイン
↓
本棚

---

## 3. 本棚画面

### 目的

登録した本を一覧で確認する。

### 表示内容

- アプリ名
- 本を追加ボタン
- 並び替え選択
- 本の一覧

### 本の一覧に表示する情報

- タイトル
- 著者
- 評価
- 読了日時

### 並び替え

以下の順番で並び替えられる。

- 読了日時が新しい順
- 読了日時が古い順
- 評価が高い順
- 評価が低い順
- 著者名順

### 操作

- 本を追加
- 本を選択
- 並び替え

### 遷移

本棚
├─ 本を追加 → 本登録
│              ↓
│            登録
│              ↓
│            本棚
│
└─ 本を選択 → 本詳細

---

## 4. 本登録画面

### 目的

読了した本を登録する。

### 入力項目

| 項目 | 必須 | 内容 |
|---|---|---|
| タイトル | ○ | 本のタイトル |
| 著者 | ○ | 著者名 |
| 評価 | ○ | 1〜5 |
| 読了日時 | ○ | 読み終えた日時 |

### 操作

- 登録
- キャンセル

### バリデーション

- タイトルが空の場合は登録できない
- 著者が空の場合は登録できない
- 評価は1〜5の範囲
- 読了日時が不正な場合は登録できない

### 遷移

本登録
├─ 登録 → 本棚
└─ キャンセル → 本棚

---

│         本詳細
│

### 入力項目

### 目的

誤操作による本の削除を防ぐ。

- 削除

### 遷移

削除確認
├─ キャンセル → 本詳細
└─ 削除 → 本棚

## 8. 画面全体の遷移

ログイン
↓
本棚
├─ 本を追加 → 本登録 → 本棚
│

## 9. MVPのUX方針

### 基本方針

「読んだ本を素早く記録できること」を優先する。

### 本の登録フロー

本棚
↓
本を追加
↓
4項目入力
↓
登録
↓
本棚

### デザイン方針

- シンプル
- スマートフォンで使いやすい
- 情報を詰め込みすぎない
- 本の一覧性を重視
- 登録操作をできるだけ短くする
